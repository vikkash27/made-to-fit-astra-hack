# Implementation decisions

- Use the installed native Apple Silicon Python 3.12 runtime and resolved CadQuery 2.8 wheels. CadQuery import, valid solids and genuine STEP/STL round-trips were tested. Retain uv.lock and .python-version.
- Keep all backend files at this folder's root, ready to insert as backend/ in the Lovable scaffold. The user moved this folder to /Users/vikkash/dev/made-to-fit-backend; editable-install and registered artifact paths were repaired.
- Use SQLite JSON records with explicit transactions and schema version 1. Operation IDs are scoped to operation kind/project/part/revision and hash the validated request. Changed input with a reused key is a conflict.
- Run authored bounded CAD handlers in short-lived subprocesses, serialized by the application dispatcher, with a configured timeout. No eval, model-generated Python or shell is accepted. Flat DAG: 100 nodes, 12 parts, depth 12.
- Enclosure helper lowers to the same box/subtract/assembly recipe as custom solids. Hardware envelopes remain independent nonprintable references. Base/lid are a plain two-part shell, with closure mechanism unverified.
- Tessellate the same kernel solids into local per-part GLB/JSON mesh. Convert mm/Z up to m/Y up exactly once during preview export. Assembly GLB contains converted transforms. STEP/STL retain engineering mm and the declared local/assembled frame.
- Freeze design, evidence/source snapshots and reviewed lock basis before CAD. Candidate artifacts/checks are revision/hash linked. Accepted pointers only change after complete artifacts, passing applicable checks and matching current parent/draft/inventory. A failed candidate never replaces the pointer.
- Separate reference appearance from engineering state. Rodin originals and derived previews have explicit unreviewed calibration until a user reviews it. Dimensions and pose changes reuse visual assets.
- Use official Responses function schemas with strict simple argument objects; DesignSpec is supplied as validated JSON in a two-stage tool, avoiding recursive/tuple schema assumptions in the vendor strict subset. Disable concurrent tool execution. Budget model calls, rounds, wall time and candidate attempts.
- Keep external submissions idempotent locally, disable OpenAI SDK automatic retries, and persist Rodin submission intent before the request. Rodin status uses jobs.subscription_key; download uses top-level uuid. HTTP 201 is successful when error is absent. Unknown submission does not imply failed generation.
- Cache actually retrieved public HTTPS manufacturer sources, with size limits, hashes and page locations. Block private/reserved addresses and revalidate redirects. Prefer manual dimensions when source identity or assembled height is unresolved.
- Poll real states; do not synthesize percentages. Retain concise tool activity and usage metadata, never private reasoning. Local app is a single-process hackathon backend; production auth, queue infrastructure and public deployment are outside this implementation.
