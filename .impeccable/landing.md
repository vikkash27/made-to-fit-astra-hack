# Made to Fit landing

Mode: Persuade with direct project intake. Preserve the graphite, ivory and orange identity, Inter Tight/Geist typography and supplied example enclosure image.

User emphasis: lead with finding useful projects in the electronics people own; also make developing, assembling and iterating on existing projects visible.

The hero says “Make more of the parts you have.” Parts discovery and an existing idea/project share the same composer and backend intake. Photo choice, specification links and manual parts remain available. The composer has a persistent label, a responsive action row, preserved drafts on errors and disabled controls while starting.

The example image is a separate, visibly labelled illustrative assembly, never a result from the visitor’s parts. An ordered workflow explains reviewed parts, project direction/dependencies, confirmed dimensions and checked revisions, then explicit acceptance and revision-linked print files/assembly guidance. Copy promises no guaranteed fit, electrical validation or preconfigured slicing.

Mobile puts intake before imagery; desktop pairs intake and imagery. Existing backend status/sample labels remain in the shared header. No provider/payment marketing or new artwork is needed.

Verified at desktop and phone widths, with existing frontend tests, type-check and production build. Mechanical scan found only existing shared-component/design-document advisories outside the landing additions.
